## **Our Manifesto**

If you are going to dream,
make it an impossible one.
And then, make it happen.

If you are traveling new paths,
be up for doing it alone.

If you’re proud of where you are from,
make where you’re from proud of you.

If you’re going to compete,
start where everybody else finishes.

If you’re looking for a reaction,
don’t settle for anything less than “woah!”

If you’re going to start something,
start something new.
The world doesn’t need another thing
just like the other thing.

And if you are looking for the
future, stop looking. Make it.
